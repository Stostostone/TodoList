# Simple TodoList v0.1.0

A lightweight desktop Todo application built with Java and JavaFX.

> [!NOTE]
> I will rewrite the UI using FXML in a new branch.

## Features

* Add / Edit / Delete Todo
* JavaFX GUI
* BorderPane navigation layout
* Service-based architecture
* Dynamic ListView refresh
* Multi-page UI structure

## Project Structure

```text
src
├── model
├── service
└── ui
```

## Technologies

* Java 21
* JavaFX 21
